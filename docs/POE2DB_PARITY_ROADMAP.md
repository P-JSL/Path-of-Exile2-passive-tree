# PoE2DB 수준 시각화·게임 배분 규칙 정합화 로드맵

> 범위: 현재 `P-JSL/Path-of-Exile2-passive-tree` 저장소의 게임 데이터, Canvas 렌더러, 포인트 계획기.
> 원칙: **GGG/PoB/PoE2DB의 공개 게임 데이터에 근거**하고 사이트 디자인이나 JavaScript 원본을 복제하지 않습니다. 실제 게임 동작으로 확인되지 않은 제한은 추측해 추가하지 않습니다.

## 기준 원본

- 패시브 위치·연결·플래그: 저장소 `data/tree.json` (PoB 2의 `0_5` 내보내기).
- 그래픽: [GGG poe2-skilltree-export](https://github.com/grindinggear/poe2-skilltree-export), 커밋 `bd87e6512c92b868542eddfb1ba4ea8b6dc2da36`의 공개 WebP 스프라이트.
- 한국어 명칭·설명: 배포 시 PoE2DB 한/영 게임 데이터 교차 검사. ID와 영문 원본이 일치하는 항목의 번역만 직접 사용.
- 아틀라스·제네시스: 기존 RePoE 추출본, 별도 트리 검증이 필요함.

## 2차 적용: 데이터 해석·성능·빌드 가져오기 (PR 검증 대상)

- `assets/spatial-index.js`: 정적 세계 좌표 인덱스로 화면에 들어오는 노드·연결선과 터치 대상을 선별합니다.
- `assets/renderer.js`: 실제 노드 그룹 중심에 궤도 연결 원호를 배치하고, 상호작용 중 고비용 노드 스프라이트를 줄이며 핀치 종료 후 단일 터치 이동을 복구합니다. 무기세트 1/2 원본 선택 노드를 링으로 표시합니다.
- 데스크톱에서 양쪽 패널을 접어 넓은 지도 탐색을 지원하며, 검색용 한국어 문자열을 장면 단위로 캐싱합니다.
- `assets/pob-import.js`: PoB2 URL-safe Base64/zlib/XML 디코딩, 모든 Spec/스킬 세트/장비 세트/설정 및 주얼 노드 참고 정보 파싱. 압축 해제 크기 제한 및 외부 엔티티 차단.
- 가져온 ID와 현재 내장 `0_5` 데이터 대조, 미일치/타 전직 경고, 기존 계획 덮어쓰기 확인 및 원본 코드 별도 보관. PoB1과 공유 링크 URL은 미지원.
- 자동 테스트에서 지원되는 원본 데이터/파서/공간 탐색 회귀를 확인합니다. **실기기 프레임 속도, 패치간 노드 매핑, 계산 엔진 완전 동등성은 미검증입니다.**

## 번역 검증 게이트 추가

배포할 때 `scripts/build-translation-coverage.mjs`가 각 트리의 한글 명칭·효과 문구 적용 범위를
`data/translation-coverage.json`에 기록합니다. 미번역 원문과 예시 노드 ID를 누락 없이 식별하되,
게임 원본 데이터와 저장된 사용자 계획은 변경하지 않습니다. 이 결과는 **번역 품질 인증이 아닙니다.**

## 후속 구현 대상 (현재 미완료)

1. **무기 세트 I/II:** 공용·무기 세트별 노드 세트, 포인트 회수의 쌍 규칙, 연결성, 전용 색상과 활성 무기 세트별 효과. 원본 게임의 제한 목록(예: 일부 특수 노드/주얼 소켓의 무기 세트 전용 배분 불가)을 공식 데이터 기준으로 확인합니다.
2. **전직 포인트·전환:** 시련/퀘스트 실제 보상량, 8포인트 한도와 예외, 전직 변경, 직업/전직별 대체 노드 ID `isSwitchable/options` 동작. 일률적인 숫자만 적용하지 않습니다.
3. **주얼·반경·특수 획득:** 주얼 장착 및 반경 효과, 선택 변경, 기형/특수 소켓과 장비·보상으로 얻은 포인트, `isFreeAllocate` 자동 할당 시점.
4. **렌더링 정확도:** 원본 `nodeOverlay` 세부 차이, 노드별 프레임 및 배경 스케일, 원본 orbit 연결선·선택/중간 상태·애니메이션·돋보기, 아틀라스/제네시스 전용 아이콘 및 프레임. 클래스·전직별 시각 비교 스냅샷 필요.
5. **빌드 호환성:** PoB / PoE2DB 배분 코드를 검증해 import/export, 무기 세트, 선택형 능력치, 전직, 주얼을 데이터 손실 없이 왕복.
6. **버전 갱신:** 저장소의 `0_5` 트리·오프라인 번역·GGG 그래픽의 패치 일치 여부를 확인하고 이후 새 버전으로 안전하게 전환. 패치 버전 혼합 시 스킬 ID 일치와 화면 외형을 각각 검증.

## 주의 사항

- GGG 게임 아트 및 용어의 권리는 원권리자에게 있습니다. `THIRD_PARTY_NOTICES.md`의 출처를 유지합니다.
- PoE2DB 원본 CSS/JS 또는 이미지 파일을 무단 복사해서 동일한 UI를 만드는 것이 아니라, 공개 게임 데이터와 독자 구현으로 기능·정확도 동등성을 목표로 합니다.

### Genesis 내부 능력치 데이터에 대한 정확성 제한

0_5 RePoE Genesis JSON은 사람이 읽을 수 있는 `stat_text`를 제공하지 않습니다(248개 노드 중 0개). 내부 `stats`는 238개 노드에 존재하지만, `brequel_...` 키를 실제 게임 효과로 해석하거나 번역할 수 없습니다. UI와 번역 커버리지 보고서에서 이 상태를 명시하며, 검증된 게임 내 설명이 확보되기 전까지 계산 엔진의 효과로 사용하지 않습니다.

### 오라클 Hidden Path 시각 비교 구현

`assets/oracle-difference.js`는 GGG 데이터의
`unlockConstraint.ascendancy === 'Oracle'`에서 새로 나타나는 일반 패시브 노드만
추출하며, 기존에 존재하는 간선 중 해당 노드에 연결되는 실제 선만 비교용으로
표시합니다. 숨김 상태에서는 비배분·비선택 점선 잔상, 표시 상태에서는 굵은
이중 링/연결선으로 보이게 하며 추가 노드 목록을 원본 그룹 ID별로 나눕니다.
표시 전환·목록 선택은 기존 사용자의 Canvas 중심 및 확대율을 변경하지 않습니다.
이것은 공개 게임 데이터에 정의된 `Oracle` 플래그의 차이를 시각화한 것이며
정식 버전 패치와의 게임 내 동등성 검증을 대신하지 않습니다.
