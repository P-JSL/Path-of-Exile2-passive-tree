# Exile Tree — Path of Exile 2 Passive & Ascendancy Tree

[한국어 설명]

PoE2의 **실제 패시브 트리 데이터**를 브라우저에서 확인하고 계획할 수 있는 정적 웹사이트입니다. PoE2DB처럼 패시브 노드의 위치·연결선·툴팁·직업 및 전직·아틀라스·제네시스 트리 전환을 지원합니다. 개발 과정에서 임의의 패시브를 만들지 않으며, 게임 데이터 추출본을 저장소에 포함합니다.

## 바로 사용하기

- **웹사이트:** https://p-jsl.github.io/Path-of-Exile2-passive-tree/ (저장소의 GitHub Pages를 활성화한 후)
- **소스:** https://github.com/P-JSL/Path-of-Exile2-passive-tree
- 로컬: 번역과 용어 메모까지 확인하려면 `node scripts/build-ko-stats.mjs`, `node scripts/build-keyword-notes.mjs`, `node scripts/bundle-tree-art.mjs`를 실행한 다음 `python3 -m http.server 8000`으로 서버를 시작하고 `http://localhost:8000`으로 접속합니다. (`file://` 실행은 지원하지 않습니다.)

### 기능

- 8개 기본 직업과 공개 추출 데이터에 존재하는 22개 전직의 노드/연결선/효과 전체 표시
- 독립된 **아틀라스 트리**와 **제네시스 트리**도 원본 추출 데이터로 제공
- 일반 패시브와 전직 패시브 트리 탭, 각 기본 직업 및 전직 변경
- 실제 스킬 ID를 이용한 노드 검색, 효과 설명, 자동 연결 경로 계획 및 회수
- 오라클의 `The Unseen Path` 선행 조건과 전용 197개 패시브 노드 표시
- PC 마우스휠·드래그, iPhone Safari 한 손가락 이동·두 손가락 핀치 확대·축소
- 기본 한국어 / 영어 언어 전환, 배분한 노드별 우측 목록 및 능력치 선택형 노드의 힘·민첩·지능 지정
- 설명에서 점선 밑줄과 `ⓘ`로 표시되는 게임 용어를 클릭·터치하면 한국어/영어 상세 메모가 열립니다. 메모의 게임 설명 출처는 PoE2DB 용어집입니다.
- 로컬 저장, 링크 공유, 모바일 전용 메뉴 및 노드 상세 패널
- GitHub Pages용 정적 사이트, 별도 프레임워크·CDN 런타임 의존성 없음
- PoB2(다른 사람의 Path of Building 2 포함) 공유 코드 또는 원본 XML 가져오기, 활성 패시브/전직 표시, 여러 트리 스펙 선택, 무기 세트별 색상 강조
- PoB2 젬·아이템·주얼·설정·계산 스냅샷을 원본 데이터로 읽기 전용 표시. 입력 코드는 브라우저 안에서 처리

### 2026-11-20 개선 및 진단

- 가져온 PoB2에서 장착된 주얼 소켓을 지도에 보라색 테두리로 표시하고, 노드 상세에서 원본 주얼 설명을 확인할 수 있습니다. 원본 속성을 재계산하지 않습니다.
- PoB2 원본 `Spec.nodes`만 실제 배분으로 가져옵니다. `WeaponSet1/2`는 배분 모드의 마커로만 사용하며, 누락된 노드 ID를 임의로 추가하지 않고 경고합니다.
- PoB2 가져오기 후 상단 **전체 / W1 / W2** 전환으로 공통 패시브와 무기 세트별 원본 배분을 분리해 표시합니다. W1/W2는 읽기 전용입니다. 원본 데이터는 변경하지 않습니다.
- 다중 언어 패시브 검색, 검색 노드 강조, 경로·추가 포인트 미리보기, 좌우 패널 간소화, 이동 중 Canvas 저화질 일괄 그리기를 적용했습니다.
- 브라우저 URL 뒤에 `?perf=1`을 추가하면 캔버스 재그리기 **P95 시간**, 프레임 간격 P95 및 해당 구간의 **추정 FPS**가 나타납니다. 유휴 시간이나 실제 게임 FPS를 의미하지 않으며, 브라우저/장치의 성능 측정값을 사용자가 직접 확인해야 합니다.
- iOS Safari, 대형 모니터, 오래된 내장 GPU 등 다양한 환경에서 성능 검증이 남아 있습니다. 벤치마크 수치를 측정하지 않은 상태에서 개선율이나 버벅임 해결을 보장하지 않습니다.

### 한국어 번역 정합성 확인

GitHub Pages 빌드에서 `scripts/build-ko-stats.mjs` 다음으로 `scripts/build-translation-coverage.mjs`를 실행합니다.
배포 산출물의 `data/translation-coverage.json`에 일반·아틀라스·제네시스 노드별 번역 문구 비율과 번역이 확인되지 않은 원문 목록을 저장합니다.
이 값은 원문 대비 표시 문구가 변경됐는지만 집계합니다. **번역 정확도나 최신 패치의 게임 내 반영률을 보증하지 않습니다.**
신뢰할 출처가 없는 원문은 임의 번역하지 않고 표시되도록 기존 정책을 유지합니다.

### Path of Building 2 코드 사용

1. PoB2의 **Import/Export → Generate** 에서 공유 코드를 복사합니다. 타인이 만든 PoB2 공유 코드도 사용할 수 있습니다.
2. 사이트 왼쪽의 **Path of Building 2 가져오기** 입력란에 코드를 붙여넣고 **빌드 불러오기**를 클릭합니다. (원본 `<PathOfBuilding2>` XML도 가능)
3. 가져온 캐릭터의 실제 노드 ID와 현재 내장 트리를 대조해 해당 직업/전직의 배분을 표시합니다. 이전 계획이 있으면 교체 확인을 요청합니다. 색상 링: 금색 W1, 보라색 W2.
4. 공유 코드가 적용되면 중앙 화면에 **PoB 빌드 상세 보기**가 열립니다. 장비 슬롯, PoB 원본 계산 능력치, 스킬·보조 젬·주얼을 확인하고 상단의 **패시브 트리 보기**로 전환할 수 있습니다.
5. 오른쪽 **가져온 PoB2 빌드**에서 다른 패시브 구성, 젬·장비·주얼·설정·PoB 계산 스냅샷의 전체 원문을 열람할 수 있습니다. 원본 코드 복사 및 브라우저에 저장된 원본 삭제를 지원합니다.

**제약:** 외부 URL 주소를 직접 넣는 방식이나 PoE1용 PoB 코드는 지원하지 않습니다. PoB 계산 엔진을 실행하지 않으므로 게임 내 DPS/방어 계산과 무기세트별 배분 제약을 완전히 재현하지 않습니다. 새 패치나 다른 트리 버전의 노드 ID가 일치하지 않으면 경고하고 임의로 치환하지 않습니다. 가져온 원본 PoB 코드는 계획 변경으로 재작성되지 않습니다. 원본 저장은 해당 브라우저의 로컬 저장소를 사용합니다. 실제 PoB2 코드 및 모바일 실기기에서 추가 상호운용 검증이 필요합니다.

### 데이터 출처 및 범위

- `data/tree.json`: [Path of Building Community for PoE2](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2/blob/dev/src/TreeData/0_5/tree.json)의 **0_5** 버전 노드·연결 데이터, GGG [PoE2 공식 패시브 트리 내보내기](https://github.com/grindinggear/poe2-skilltree-export) 기반.
- `data/atlas.json` 및 `data/genesis.json`: [RePoE PoE2 추출 데이터](https://github.com/repoe-fork/poe2/tree/master/data/passive_skill_trees)의 `Atlas.json` / `BrequelTree.json` 게임 데이터 스냅샷. 전용 adapter로 원본 좌표와 그래프 링크를 렌더링합니다.
- 패시브 좌표는 그룹 좌표와 공식 orbit 반경·각도 데이터로 계산합니다. 스킬 ID·원본 수치·연결 정보는 유지하고, 노드 이름과 효과의 화면 표시 문구만 검증된 영한 사전 및 동일 ID 대조 결과로 번역합니다.
- 화면 디자인과 Canvas 구현은 이 저장소의 자체 구현입니다. 배포 시 GGG 공식 내보내기의 원본 WebP 아이콘·프레임·기본 직업 배경을 검증된 커밋에서 내려받아 포함합니다. 게임 원본 권리는 GGG에 있으며 PoE2DB 사이트 코드·UI 에셋은 복사하지 않습니다.
- 전직 목록에는 데이터에 실제 노드가 있는 전직만 표시합니다. 원본 데이터에 메타데이터만 있는 `Abyssal Lich`는 잘못된 빈 트리를 보여주지 않도록 제외됩니다.
- **아틀라스·제네시스**는 별도 추출본에서 제공하며, 시각화와 연결형 계획은 지원합니다. 다른 시즌의 모든 특수·과거 트리까지 포함하는 것은 아닙니다.
- 일부 제네시스 노드는 원본에 사람이 읽는 효과 문구가 없어 원본 내부 스탯 키/수치가 대신 표시됩니다. 출처에 없는 설명을 임의로 만들지 않습니다.
- 한국어 스킬 용어 메모는 배포 시 PoE2DB 한국어/영어 용어집에서 정적으로 생성하며, 페이지를 탐색하는 동안 외부 서비스에 용어 조회를 요청하지 않습니다. 상세한 출처는 `THIRD_PARTY_NOTICES.md`를 참고하세요.
- 원본과 대응하는 일반/주요/핵심 노드 4,545개는 GGG 스프라이트에서 표시할 수 있으며, 원본 이미지 데이터가 없는 경우 자체 벡터 도형으로 안전하게 표시합니다. 모바일 실기기 렌더링과 아틀라스·제네시스 전용 그래픽은 별도 검증이 필요합니다.
- 전직/패시브 계획은 설명용이며 실제 게임에 자동 적용되지 않습니다. 연결성·게임에 정의된 선택형 노드·해금 조건·무료 노드·사용자가 입력한 포인트 한도를 검사합니다. **무기 세트별 배분, 주얼 반경, 직업별 대체 노드, 전직 보상 자동 계산 등은 아직 미구현**이므로 게임의 모든 제약을 정확히 재현한다고 볼 수 없습니다.
- 구현 상태와 남은 검증 항목은 [정합화 로드맵](docs/POE2DB_PARITY_ROADMAP.md)을 확인하세요.

### 검증

```sh
node --test tests/*.test.mjs
node scripts/validate.mjs
```

검증은 데이터의 전체 노드 수, 전직/클래스 존재 여부, 노드 ID 연결의 무결성, 오라클 데이터 존재 여부와 경로 탐색/회수 로직을 확인합니다.

### GitHub Pages 배포

기본 브랜치 `main`에 커밋하면 `.github/workflows/pages.yml`이 정적 사이트를 검증하고 배포합니다. **최초에는** GitHub 저장소의 `Settings → Pages → Build and deployment → Source`를 **GitHub Actions**로 설정해야 합니다. 배포가 완료되면 위 웹사이트 URL로 접속할 수 있습니다.

### 업데이트

패치 후 `data/tree.json`을 검증된 PoB 2 게임 버전의 JSON으로 교체하고 `scripts/validate.mjs`를 실행하세요. 원본 노드 ID·스탯·링크를 임의로 편집하지 않습니다. 업데이트 전후 실제 최신 버전과 모델 호환을 별도로 확인해야 합니다.

### Genesis 원문 출처 제약

현재 Genesis 트리(`data/genesis.json`)의 248개 노드에는 사람이 읽을 수 있는 `stat_text`가 없으며, 그중 238개는 내부 `stats` 키·수치만 포함합니다. 해당 정보는 게임 내 효과나 한글 번역이 아닙니다. 상세 패널에서는 원본 키를 보존하되 주의 표시를 함께 제공합니다. 이 내부 키를 임의로 한국어 게임 효과로 변환하지 않습니다.

### PoB2 장비·주얼의 원본 옵션 확인

PoB2 프로필의 장비·주얼에서 **원본 옵션 전체 보기**를 눌러 전체 원문을 확인할 수 있습니다.
기존 짧은 장비 요약과 레이아웃을 유지하면서 iPhone 등 터치 환경에서도 원본 옵션을 볼 수 있습니다.
원본 문구는 텍스트로만 렌더링하며, 게임 능력치를 별도로 계산하거나 다시 해석하지 않습니다.

### PoB2 장비·스킬 구성 전환

원본 PoB2 코드에 여러 `ItemSet` 또는 `SkillSet`이 있는 경우 프로필 상단에서
각 구성의 원본을 읽기 전용으로 전환해 볼 수 있습니다. 기본 표시는 PoB2가
지정한 `activeItemSet` 및 `activeSkillSet`을 사용합니다.
구성 전환은 원본·저장된 계획을 수정하지 않으며, PoB 능력치 스냅샷을 다시 계산하지 않습니다.

### 오라클 '보이지 않는 길' 위치 비교

오라클 전직을 선택한 상태에서 **보이지 않는 길 노드 표시**를 켜면 새로 등장하는
패시브 노드가 두 겹의 밝은 보라색 원으로, 새 연결선은 보라색으로 강조됩니다.
표시를 끄면 새 패시브가 실제 트리에서는 제거되는 대신 비교용 **점선 잔상**으로
표시되므로 무엇이 어느 자리에 생기는지 비교할 수 있습니다. 실제 배분은 되지 않습니다.

**추가되는 위치를 지도에 강조**를 끄면 점선/실선 비교 표시도 해제됩니다.
왼쪽의 **추가되는 노드 위치·이름 전체 보기**에서 게임 원본 그룹별 노드명과
ID를 확인할 수 있습니다. 목록에서 노드를 선택하면 필요한 경우 노드를 표시하되
현재 지도 위치와 확대율은 변경하지 않습니다. 오라클 전직의 선행 조건과 실제
배분 규칙은 기존 검사를 유지합니다.

### PoB2 빌드의 한국어 상세 표시

한국어 선택 시 PoB2 가져오기 화면의 게임 내 장비 기본형·고유 아이템명·스킬 젬명과
일부 장비 속성 및 계산 결과의 명칭을 한국어로 표시합니다.
장비/주얼의 **옵션 상세는 기본 펼침**이며, 각 장비 카드는 모바일에서 한 열로 배치합니다.
영어 선택 시 이전처럼 원문과 접힌 옵션을 보여줍니다.
수치의 정밀도와 PoB2 원본 코드는 유지하며, 화면만 현지화합니다.

용어 데이터 `data/pob-ko.json`은 [PobTools-zh의 PoE2 ko-KR 데이터](https://github.com/Hsiung-Shao/PobTools-zh/tree/main/pob-zh-engine/dist/Data/poe2/ko-KR)에
수록된 게임 텍스트 기반 한국어 대응표를 가져온 것입니다.
게임 자료와 게임 내 번역의 권리는 Grinding Gear Games에 있으며 MIT 라이선스가 적용되는
프로젝트의 자체 소스 코드와 구분합니다. PoB2 버전별 신규 용어, 생성되는 희귀 아이템의
영문 조합 이름 및 대응하지 못하는 복잡한 접두/접미 속성은 **근거 없는 임의 번역 대신
원문을 그대로 남깁니다.** 저장된 원본 텍스트와 계산 결과를 바꾸지 않습니다.

희귀 아이템의 무작위 생성 이름은 정확한 전체 조합 번역 사전이 없을 수 있습니다.
확인된 GGG 한국어 접두·접미 구성어가 모두 존재하는 이름에 한해 조합된
한국어 이름을 보여주고 **구성어 번역(전체 이름은 미검증)**임을 명시하며
원래 영어 이름을 함께 표시합니다. 확인할 수 없는 조합은 원문을 유지합니다.
